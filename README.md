## How to Use
Many files use the online-judge format (for example, `class Solution`) rather than a complete standalone program. You can paste them into the matching problem on an online judge.

To compile a standalone C++ program locally, add the required headers and a `main()` function, then run:

```bash
g++ -std=c++17 solution.cpp -o solution
./solution
```

For the queue implementation, the original problem reference is included in the source file.
